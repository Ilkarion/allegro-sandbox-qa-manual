## 2. Testing Goals

The goal was to check the main features of Allegro Sandbox and look for possible bugs.

I tested the application by using its features and checking how they worked. As there were no formal requirements, I used the website's behavior to understand what the expected results should be.

## 3. Tested Areas

During exploratory testing, I checked the following areas:

- **Authentication**
  - Login
  - Registration

- **Search**
  - Search input
  - Categories

- **Products**
  - Product details
  - Product selection

- **Cart**
  - Adding products
  - Removing products
  - Changing product quantities
  - Checking price calculations

## 4. Testing Approach

I explored the website and checked how it worked in different situations.

I used the following testing methods:

- Functional testing
- Positive and negative testing
- Boundary value analysis
- UI testing
- Responsive testing

I checked user actions, input fields, product selection, cart operations, and the website's appearance on different screen sizes.
